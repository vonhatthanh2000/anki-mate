# ADR 0012: Add a Meaning Overview before language analysis

Status: Accepted

The 3-sentence minimum is superseded by ADR 0022; the overview structure and 5-sentence maximum remain accepted.

## Context

Understanding isolated expressions does not guarantee understanding the speaker's overall argument, story, tone, or implications. The learner wants to understand the video's concept deeply before listening again.

## Decision

Begin every transcript lesson with a concise Meaning Overview containing:

- Up to 5 summary sentences, with no minimum
- The main point and supporting ideas
- Tone and register
- Implied meaning, cultural context, or references necessary for comprehension

Place the highlighted transcript and detailed language analysis after this overview.

## Consequences

- The lesson covers discourse-level meaning as well as language items.
- Analysis must distinguish source-supported implications from invented background information.
- The overview should remain concise for 1–3 minute sources.
- Learners can establish the conceptual frame before studying individual expressions.
