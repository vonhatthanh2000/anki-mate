# Domain Glossary

## BoostVocab

The existing feature that enriches learner-supplied vocabulary and supports saving and Anki export.

## Natural English note

The dedicated Anki note type for transcript-derived expressions and grammar patterns. It preserves category, usage, authentic source context, a new example, CEFR estimate, and source URL instead of forcing the item into the vocabulary-only schema.

## Transcript lesson

A listening-comprehension experience derived from the transcript of one short YouTube or TikTok video. Analysis and practice prepare the learner to understand the source more fully when listening again.

## Language item

A transcript excerpt selected for learning and classified as vocabulary, an idiom, a phrasal verb, a collocation, slang, or a grammar pattern.

## Source excerpt

The exact surrounding transcript text that demonstrates how a language item was used naturally in the source video.

## CEFR level

An estimated proficiency level from the Common European Framework of Reference for Languages. In transcript lessons it prioritizes material rather than acting as a strict exclusion threshold; it is not presented as an objective certification.

## Selection rationale

A short explanation of why a language item deserves attention, such as being essential to the source meaning, commonly reusable, subtly used, or above the learner's current level.

## Natural English

English that is idiomatic and appropriate for a particular context, register, audience, and medium—not merely grammatically correct English.

## Learning loop

The sequence of transcript analysis, focused language study, active practice, optional Anki export, and another listen to the original video.

## Reusable language

Language that occurs commonly enough, or transfers across enough situations, to justify active practice beyond understanding the current video.

## High-value language

A language item selected because it materially improves understanding of the source, is commonly reusable, or is especially relevant above the learner's current level. High value is a ranking judgment, not a category quota.

## Contextual recognition

An exercise that checks whether the learner can recognize meaning or appropriate usage within context, such as a cloze, usage choice, or sentence transformation.

## Active production

A task requiring the learner to retrieve and use target language in a paraphrase or original example, followed by feedback on correctness and naturalness.

## Transcript acquisition

The process of obtaining lesson text from accessible captions, an authorized learner-supplied media file through speech-to-text, or a manually pasted transcript.

## Temporary media

An audio or video file used only long enough to produce a transcript, then deleted rather than retained as lesson content.

## Best-effort acquisition

A local attempt to obtain captions or media from a submitted URL without promising that every platform URL will work. File upload and transcript paste are fallback paths.
