# Issue tracker: GitHub

Issues and specs for this repo live as GitHub issues. Use the `gh` CLI for all operations.

The repository is inferred from `git remote -v`.

- Publishing means creating a GitHub issue.
- Fetching a ticket means reading the issue and its comments.
- Labels are managed with `gh issue edit`.
- Pull requests are not a triage request surface.
- Wayfinder uses GitHub issues, sub-issues, and native dependencies where available.
